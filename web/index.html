Your packages. One offline installer.

Build Omarchy your way.

Choose pacman packages while you have internet. Build a custom ISO that carries them and installs them with Omarchy. Once the USB is written, the destination computer needs no connection.

01 / SELECT

Choose packages

Choose an Omarchy release or a current channel, then search its package repository. Dependencies are included automatically.

Checking available versions…

    Loading package catalog…
    Your selected packages will appear here.
    02 / BUILD

    Bundle the ISO

    The official builder downloads package files and their dependencies, creates the offline mirror, and produces the bootable ISO.

    Checking Docker…

    Requires Docker running Linux containers, Git, internet, and sufficient disk space on this computer.

    03 / WRITE

    Make the USB

    Select the finished ISO and a removable USB disk. The entire disk will be erased and the written image verified.
